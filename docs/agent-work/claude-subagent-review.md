# Former Claude Code review subagent route

## Claude Code review subagent from Claude Code

Claude Code runs now request [the Claude CI review](./claude-ci-review.md#claude-ci-review-from-claude-code). The project's
`reviewer` subagent can still perform [advisory pre-flight](./change-delivery.md#deliver-a-draft-when-advisory-pre-flight-is-unavailable).

The [former independent-review procedure](https://github.com/axross/runners/blob/a070ff3488b3df526ef5083e77c908ecc383c49c/docs/operations/development-workflow.md#claude-code-review-subagent-from-claude-code) records the worktree,
publication and cleanup requirements that applied when the subagent served as
the independent reviewer.
